# Anannt PSAT Path

SAT feeder for **PSAT/NMSQT** and **PSAT 10**, mounted at `https://study.anannt.ae/psat`.

Two public lessons (slope in context, some versus all) are open without an account. This path does **not** sell AP. After the gate, the only mentoring CTA is Digital SAT coaching.

## Public without an account

- Subject home: `/psat`
- Exam guide: `/psat/method`
- Lesson 1 — slope in context: `/psat/learn/M2/M2-L1`
- Lesson 2 — some versus all: `/psat/learn/RW1/RW1-L1`
- Diagnostic start: `/psat/diagnostic`

After lesson 2, a diagnostic submit, or a visit to practice / mocks, the app redirects to `https://study.anannt.ae/start?subject=psat`.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43151/psat](http://127.0.0.1:43151/psat).
